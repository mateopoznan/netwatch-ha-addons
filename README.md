# Netwatch for Home Assistant

Agent for reporting the Home Assistant host's local, VPN, and public IP addresses to your Netwatch dashboard.

[![Add this repository to Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fmateopoznan%2Fnetwatch-ha-addons)

## Install

1. Add this repository in **Settings → Apps → Install app → ⋮ → Repositories**.
2. Install **Netwatch Agent**.
3. In the app configuration, paste a one-use enrollment code generated by the Netwatch dashboard. Set the device name if desired.
4. Start the app. Once the first report appears in Netwatch, remove the enrollment code from the app configuration.

The agent reports every five minutes. Its device token is stored in the app's persistent `/data` directory.
